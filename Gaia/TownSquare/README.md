# TownSquare — Espacio Comunitario

Bienvenido al TownSquare de Gaia. Aquí publicamos mensajes, propuestas y conversaciones en formato de post (un archivo Markdown por post).

Reglas básicas:
- Cada post es un archivo en Gaia/TownSquare/posts/ con nombre: YYYY-MM-DD-HHMM-usuario.md (ej: 2026-08-19-1534-kevin.md).
- Usa la plantilla `TEMPLATE-post.md` para crear nuevos posts (copiar y rellenar).
- Antes de editar: `git pull` (o usar Obsidian Git: Pull).
- Después de crear/editar: `git add` → `git commit -m "t:townsquare <title> by <author>"` → `git pull --rebase` → `git push`.
- No edites los posts de otros sin coordinar.

Recomendaciones:
- Instala Obsidian Git en Obsidian y configura el repo remoto.
- Habilita "Auto pull on open" para reducir conflictos.
- Usa QuickAdd/Templater para instanciar la plantilla y renombrar el archivo con timestamp.
