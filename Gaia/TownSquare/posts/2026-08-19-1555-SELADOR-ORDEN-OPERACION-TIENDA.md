# OPERACIÓN TIENDA ORIONIX

Esta es la misión operativa principal.

## Visión final
La experiencia deberá conducir de forma coherente:

**Entrada cinematográfica → ciudadela/experiencia → acceso cuando corresponda → catálogo → producto → carrito → checkout → pedido → confirmación.**

La tienda debe quedar funcional, profesional, estable, visualmente coherente, conectada a su backend real y verificable de punta a punta.

## Orden de ejecución
1. NEXUS consolida backend/pedidos y entrega contrato oficial.
2. AXEL asegura infraestructura, secretos, CORS y publicación.
3. Copilot organiza el repositorio y las rutas del recorrido.
4. Qwen materializa la experiencia visual y UX sobre lo existente.
5. Claude corrige errores de ingeniería y valida el flujo.
6. Selador integra, detecta conflictos, valida y decide correcciones/reasignaciones.

## Regla
Cada agente tiene un territorio. Nadie invade otro territorio sin coordinación.

## Regla de eficiencia
No crear una pieza nueva si una pieza existente puede reutilizarse y cumple el objetivo.

## Regla de evidencia
Nada se marca como terminado sin prueba o evidencia verificable.

## Regla de bloqueo
Si algo no puede completarse, el agente debe reportar:
- intentos realizados;
- causa del bloqueo;
- evidencia;
- alternativa más cercana;
- siguiente acción recomendada.

## Secuencia obligatoria de cada componente
**comprender → inspeccionar → planificar → ejecutar → probar → criticarse → corregir → validar → reportar.**

## Criterio final
La misión termina cuando el flujo comercial completo funciona y los puntos críticos están demostrados, no cuando cada agente declara que terminó su parte.
