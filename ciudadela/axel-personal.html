✦ Proveedor personal

Por seguridad, esta versión guarda solo proveedor/modelo/endpoint en localStorage y nunca persiste la API key.

🔐 Regla de seguridad

No subimos claves personales a GitHub Pages. Para producción, AXEL Personal usará un puente local o un backend seguro donde la clave permanezca bajo control del usuario. Así podemos integrar múltiples proveedores sin exponer secretos en el navegador.
